# 🌤️ Weather Tracking Dashboard

A professional Python-based Weather Dashboard built with Tkinter and OpenWeather API.  
This application provides real-time weather tracking, historical data storage, analytics charts, and CSV export functionality through a modern dark-themed GUI.

---

## ✨ Features

- 🌡️ Real-time weather updates
- 🔍 Search weather by city
- 📌 Track multiple cities
- 📋 Weather history storage
- 📊 Data analysis & visualization charts
- 💾 CSV export support
- 🔄 Auto-refresh weather updates
- ⚠️ Weather alerts & warnings
- 🌙 Modern dark-themed user interface

---

## 🛠️ Technologies Used

- Python
- Tkinter
- Requests
- Matplotlib
- OpenWeather API
